# Cartella Documenti Utente (`knowledge/default/`)

Trascina o incolla qui i tuoi file da indicizzare nel sistema:
- File di testo e appunti: `.md`, `.txt`
- Documenti: `.pdf`, `.docx`, `.xlsx`, `.pptx`
- Immagini e scansioni: `.png`, `.jpg`
- Audio e video: `.mp3`, `.wav`, `.mp4`

Per indicizzarli automaticamente nella tua Knowledge Base, esegui:
```bash
./ragcli ingest default
```
oppure lasciali indicizzare dai servizi in background.
